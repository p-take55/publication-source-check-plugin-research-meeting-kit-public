# research-meeting-kit

調査と会議の振り返りを支える2つのSkillをまとめたPluginです。

## 含まれるSkill

- `research-brief` — テーマ・読者・判断したいことを確認し、一次情報を出典付きで集め、要点・根拠・次のアクションの順で短い提案資料にまとめます。書式は `skills/research-brief/references/report-format.md` にあります。
- `meeting-summary` — 会議の記録から決定事項、未解決の論点、次のアクションを分けて整理します。担当や期日が記録にないときは推測せず「未定」とします。

## セットアップ

外部サービス、MCPサーバー、認証情報は不要です。Pluginをインストールするとそのまま使えます。
